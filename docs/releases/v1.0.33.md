# 小步日常 1.0.33 内部预发布

安装包不进入 Git 或 Git LFS。构建摘要见 `release-apks/v1.0.33/` 中的文本记录。首次标签推送后尚未见 Actions 运行记录，下述 GitHub Release 附件描述为流程设计，不代表附件已实际发布。

此安装包使用仓库已有的 Android Debug 测试证书，供内部安装验证，不能作为商店正式签名版本。包名为 `com.smallsteps.checkin`，Android `versionCode` 为 34；它会按正常 Android 更新规则更新同包名、同签名的常规应用，不是独立 QA 包。请保留现有数据，不通过卸载或清空数据解决签名、版本不兼容问题。

本版包含账户资料页和“更多”入口的同步提示修正：资料保存在本机，小组同步后组内成员可看到昵称和头像。此前在 OPPO 隔离测试包当前字体与主题下已验证这两处提示完整展示；该有限样本不代表本版全部功能、所有设备或全部字号已经通过验收。

本版同时保留工作区中的 Android 原生生命周期候选改动。Expo 选图启动器和 TCP 监听关闭候选仍缺少新包完整真机回归，OPPO 已记录的间歇同步超时根因尚未确定，不将这些问题描述为全部修复。相机、相册、局域网及已有业务数据的验收范围以仓库内实际记录为准。

附件提供安装包、SHA-256 摘要、APK 元数据、签名校验输出和构建提交信息。GitHub Actions 从此标签代码重新构建；其安装包可能与本机构建具有不同字节摘要，应按同次发布附件核对。构建和自动化检查成功不等于安装启动、真机功能或全平台验收成功。

同版本的 `v1.0.33-preview.N`（`N` 为正整数）用于独立预发布重试，不移动或覆盖已有标签；应用版本仍为 1.0.33/code 34。发布说明按应用版本复用本文件，实际构建标签和源码提交以附件 `BUILD-INFO.txt` 为准。
