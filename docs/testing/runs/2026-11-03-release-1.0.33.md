## 本地产物与远程方式

- 本地文件：`dist/小步日常-1.0.33-20261103.apk`，128093087 字节；摘要 `5f0468be445addfc05b694ed420432ec7458296e8099138602ad28fc882694bf`。旁存 `.apk.sha256` 文件。
- Debug 证书 SHA-256：`fac61745dc0903786fb9ede62a962b399f7348f0bb6f899b8332667591033b9c`。这是常规包名，会按 Android 更新规则关联同包名同签名应用，不是独立 QA 包。
- 独立只读产物复核确认清单未声明 `debuggable`（默认 false）、允许系统备份、内置 JS bundle，未见数据库或签名密钥作为 APK 条目；该检查不是系统备份行为或设备隔离验证。
- 本机无 GitHub API 上传凭据，SSH 远程可用。APK 超过普通 Git 单文件限制且 `dist/` 按项目规则不入库；采用标签触发的 GitHub Actions 从推送代码重新构建，检查后上传 GitHub 预发布附件。远程构建摘要可能不同于本地，应以同次发布附件校验；远程构建和上传状态在实际执行后补记。
