# 验收记录：QA32 三星账户页大字体键盘

## 环境与步骤

- 2026-11-01，Asia/Shanghai；三星 SM-G9730 / Android 12；独立 QA 1.0.32/code 33。INPUT-002 的账户昵称、键盘与放弃草稿有限参数。
- 原系统字体缩放为 1.3，临时以 `adb shell settings put system font_scale 1.5` 设置为 1.5。通过赠券页“编辑账户资料”进入账户页，滚动到昵称，点击输入并追加临时草稿；没有点击保存。
- 系统 `dumpsys input_method` 输出 `mInputShown=true`。键盘保持展开时向上滑，界面树 `/tmp/R28M22J0K3D-qa32-font15-keyboard-scroll.xml` 显示昵称输入区域 `[74,686][1007,818]`、启用的保存资料 `[74,1001][1007,1151]`；滑动后再次确认 `mInputShown=true`。
- 按返回收起键盘并再次返回，出现放弃未保存账户资料提示，证据 `/tmp/R28M22J0K3D-qa32-font15-discard-dialog.xml`；实际点击放弃更改。系统字体恢复为 1.3，并由 `settings get system font_scale` 确认。未改正式包或保存昵称。
- 再次临时调至 1.5，重复输入与滚动，实际截图显示输入框和保存按钮完整位于展开的键盘上方；遮盖 QA 身份编号后的证据为 `/tmp/R28M22J0K3D-qa32-font15-keyboard-redacted.png`。原始截图已从设备及临时目录删除；再次放弃草稿并恢复字体 1.3。

## 结论与限制

- 部分验证：三星 1.5 倍字体下键盘展开并滚动后，截图可见昵称与保存按钮未与键盘重叠；前一次界面树显示保存按钮启用，返回会提示放弃草稿。未点击保存验证提交，不标 INPUT-002 整例通过。
- 没有测试其他表单、其他字号、iOS/Web 或读屏；无产品代码改动，本轮未重跑全量质量检查。独立 verifier 核对首次界面树坐标与放弃提示一致，并目视确认脱敏截图无重叠、身份编号已遮盖；字体值及实际离页依赖执行者当场观察，截图不证明保存成功。
