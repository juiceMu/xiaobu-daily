# 小步 · Native 设计规范

## 账户资料（2026-10-20）

- 更多页提供紧凑账户卡和独立账户资料入口，显示本机头像、昵称及未登录云账户的明确说明。昵称与赠券复用稳定身份，不创建平行的昵称设置。
- 头像支持相册图片和默认头像，预览后显式保存；照片缩小压缩并持久化，避免只保存会失效的临时文件地址。头像不加入赠券二维码、领取回执或历史身份快照。
- 沿用现有主题、16号标题、固定上方标签和紧凑按钮。选中状态须有文字及无障碍语义，不恢复常驻描边和对钩；保留触控尺寸及键盘焦点。
- 相册取消不改草稿，选图错误、保存失败保留草稿，未保存离开须确认。历史券保留原昵称；资料更新不改变身份编号或奖券记录。

## 离线扫码赠券（2026-10-20，最新）

- 「更多 → 赠送与领取」提供本机称呼、新赠券制作、扫码或粘贴领取、收发记录和领取回执。创建新赠券不消耗原有奖券；制作持久化完成才显示二维码，扫码只预览，确认时重新核对有效期及本机去重并原子保存。
- 券名自定义，选择本周有效或永久有效。本周券固定制作设备下周一00:00失效，接收不延长；预览同时展示赠送人和实际到期时间。奖券列表明确标为来自赠送方。
- 沿用五套主题、紧凑标签与控件、表单顶部留白、无装饰描边、键盘焦点与可取消确认。二维码独立保持白底黑码与安静区，避免主题色破坏扫描。相机必须显式打开、可关闭，离开页面或后台停止；无权限或不安全浏览器环境可改粘贴。
- 明确本机身份不是已认证账户、离线码无法全局防重复，不把“生成二维码”显示为已送达。发出端只有收到并确认回执后才记录领取人，回执也不宣称具备防伪能力。
- 按版本化身份、赠券、收发记录及传输/服务边界预留云迁移，不把业务逻辑写死在相机和页面中，不自动上传数据。

## 数字输入友好规范化（2026-10-20，最新）

- 所有带 numericRule 的共享数字框在输入时去除合法数字的冗余前导零：`010400 → 10400`、`000 → 0`；小数支持 `.5 → 0.5`、`00.5 → 0.5`，重复小数点仅保留第一处，如 `1..2 → 1.2`。此条覆盖此前不自动修正冗余零和点的约定。
- 输入期间允许清空及末尾点草稿，失焦时 `1. → 1`。字母、指数、负号等非法内容保留并提示，不擅自过滤成另一数字；整数框不把 `1.5` 变成 `15`，不截断精度、不夹紧越界数值。领域服务严格校验保持不变。
- 不改变原有回调、ref、无障碍、紧凑字号、无描边样式、主题及账户或奖券业务。

## 极简白：第五套可选主题（2026-10-20，最新）

- 在原有四套主题之后增加「极简白」，保留暖灰米默认及用户当前选择，不强制切换。页面纯白 `#FFFFFF`、卡片近白 `#FFFEFF` 保持干净；输入浅淡黄 `#F8F1DC`、品牌填充浅淡紫 `#E8E2F2`、主容器浅淡黄 `#F3EBD4`，前景深紫灰，淡色只落在交互面。

## 视觉方向

### 多彩语义调整（2026-10-20）

- 淡色主题按操作语义配色：蓝色用于导航与常规操作，薄荷色用于保存与确认，紫色用于奖励与选择强调，杏色用于归档，红色用于删除；取消使用透明底和中性文字。颜色与明确文字标签共同表达含义，不把所有按钮统一铺蓝。
- 图标选中使用深紫底和白色图标，与未选浅底明显区分；保留当前图标名称与读屏选中语义，不增加边框或对钩。保持紧凑尺寸，搜索图标缩至16dp。

## 导航和交互

- 底部只有「今日打卡 / 我的奖券 / 更多」三个入口；更多进入里程碑、成长记录、归档任务、奖励设置。
- 里程碑使用页内紧凑目标条直接切换，不打开整页选择器或跳转页面；目标多时支持页内搜索与明确的横向切换提示。当前与已归档分组均在本页切换，空态仍保留已归档入口。
- 暂停与归档相互独立：暂停停止记录和解锁但仍保留在当前列表；归档收进已归档列表，只读查看历史及永久奖励，可恢复到当前列表。归档不重置原启用状态，恢复后原暂停目标仍暂停、原进行中目标继续进行；已解锁刻度与已发奖券永不重置。归档须弹窗确认，删除后不可从归档恢复。
- 页面标题统一16dp、行高24dp；页面内容在顶部安全区或导航栏下再留16dp。底部导航在系统底部安全区之外额外留12dp，并同步增加底栏占位高度，不压缩按钮、不遮挡列表；继续支持系统字体缩放。此条覆盖较早的20/28dp页面标题约定。
